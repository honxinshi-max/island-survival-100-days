# 荒岛生存：百日余生

一款面向 3—5 人合作试玩的百日荒岛生存规则游戏。玩家要在饥饿、脱水、体温、疾病、战斗、资源枯竭和大型危机之间分配行动，通过采集、制造、研究、建造与能源管理完成求救信标，并维持连续三夜有效广播，在第 100 夜后至少保有一名可获救的幸存者。

## 当前文档基线

- 权威输入：`荒岛生存_核心规则补充条款_V1.2_框架校正稿.md`
- 本仓库整理版本：`V1.3-audit-draft`
- 正式平衡范围：3—5 人；1—2 人及 6—8 人不属于当前完整平衡承诺
- 模式：100 天完整版、20 天压缩试玩版
- 重要边界：本机没有检索到 V1.1 主规则书；因此 `游戏设计.md` 保留 V1.2 原文，并把无法由现有材料确认的内容明确留在“待回填边界”，不把推测写成既定规则

## 一局的核心闭环

```text
探索与发现
  → 采集食物 / 水 / 基础材料 / 稀有样本
  → 维持饱腹、水分、体温、伤病与营地安全
  → 制造工具、加工材料、研究科技
  → 建造生产、防御、医疗、能源设施
  → 建造并启动求救信标
  → 连续三夜有效广播
  → 第 100 夜结算后完成救援
```

## 本轮大漏洞审计

基于 V1.2 可见条款，本轮未发现无需上下文即可确认的 P0；确认 7 个 P1 级规则漏洞，均已在 `游戏设计.md` 给出复现路径和 V1.3 建议条文：

1. 信标里程碑允许进度跨段结转，可用较低难度检定绕过难度 11 的最终校准。
2. 开局“胜利资源预算”只验材料，不验行动天数、能源/燃料、稳定饮食饮水与保证可达性，仍可生成账面合法但实际上不可胜的地图。
3. 资源点只在恰好归零时跳过恢复，最优策略永远是留 1 份，形成无真实选择的“留一单位”漏洞。
4. 建筑耐久只要大于 0 就按满效运行，1 点耐久与满耐久没有产能差异，维修可被理性推迟到完全损坏。
5. 夜间救治可以“预支新一天第 1 点行动”，但没有债务上限和重复救治规则，同一角色可能重复预支同一个行动点。
6. 防守持续到“下一次行动开始”，被跳过行动时可能无限延长；保护也没有限制同一次攻击的递归转移。
7. 温室每天无输入地产出 2 份野菜或 1 份草药，百日模式可无水、无种子、无能源地产生 200 份野菜或 100 份草药，足以击穿资源压力。

这些条款在真实试玩前应先修“可执行性”，再调数值；不要把它们当成普通强弱平衡问题。

## 文档职责

- `游戏设计.md`：产品目标、系统闭环、漏洞审计、V1.3 建议修订，以及 V1.2 权威稿全文。
- `docs/生存系统.md`：昼夜顺序、饱腹/水分/体温、伤势疾病、战斗濒死和资源恢复。
- `docs/建造系统.md`：项目、研究、建筑、能源、设备上限与求救信标。

- `更新日志.md`：每轮规则修订、证据状态与仍待实测的决定。

## 首轮反馈门

每局记录 10 项核心指标：人数职业、是否获救、稳定饮水/食物天数、信标关键节点、五类生命损失、首次枯竭、设备被迫关闭、角色行动贡献，以及三个“没有真实选择”的时刻。下一轮只依据这些记录改变一个压力源，禁止同时改材料、进度和伤害而失去因果。
