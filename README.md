# 荒岛生存：百日余生

一款面向 3—5 人合作试玩的百日荒岛生存规则游戏。玩家要在饥饿、脱水、体温、疾病、战斗、资源枯竭和大型危机之间分配行动，通过采集、制造、研究、建造与能源管理完成求救信标，并维持连续三夜有效广播，在第 100 夜后至少保有一名可获救的幸存者。

## 一局的核心闭环

```text
探索与发现
  → 采集食物 / 水 / 基础材料 / 稀有样本
  → 维持饱腹、水分、体温、伤病与营地安全
  → 制造工具、加工材料、研究科技
  → 建造生产、防御、医疗、能源设施
  → 建造并启动求救信标
  → 连续三夜有效广播
  → 第 100 夜结算后完成救援
```

## 三轮可执行性审计

基于 V1.2 可见条款，目前未发现无需缺失卡表即可确认的 P0。第一轮确认 7 个 P1，均已在 `游戏设计.md` 给出复现路径和 V1.3 建议条文：

1. 信标里程碑允许进度跨段结转，可用较低难度检定绕过难度 11 的最终校准。
2. 开局“胜利资源预算”只验材料，不验行动天数、能源/燃料、稳定饮食饮水与保证可达性，仍可生成账面合法但实际上不可胜的地图。
3. 资源点只在恰好归零时跳过恢复，最优策略永远是留 1 份，形成无真实选择的“留一单位”漏洞。
4. 建筑耐久只要大于 0 就按满效运行，1 点耐久与满耐久没有产能差异，维修可被理性推迟到完全损坏。
5. 夜间救治可以“预支新一天第 1 点行动”，但没有债务上限和重复救治规则，同一角色可能重复预支同一个行动点。
6. 防守持续到“下一次行动开始”，被跳过行动时可能无限延长；保护也没有限制同一次攻击的递归转移。
7. 温室每天无输入地产出 2 份野菜或 1 份草药，百日模式可无水、无种子、无能源地产生 200 份野菜或 100 份草药，足以击穿资源压力。

第二轮继续追问“同一局面能否只得到一种结算”，新增 7 个 P1 与 2 个 P2：

1. 项目第一次失败前是否付材料、协助是否花行动；
2. 高强度行动、体力类检定和休息的统一标签；
3. 清晨伤病、紧急救治、资源恢复和自动产出的固定顺序；
4. 当日能源、跨夜储能、设备名单和名额争用；
5. 信标广播中断、停机、重启和锁定丢失的状态机；
6. 稳定产量的三日投影与隐藏可再生点的评分分母；
7. 驯兽上限下降及受伤动物的处理期限；
8. 事件整数权重的实体抽取法与同夜危机队列；
9. 终局健康闭合、胜负优先级及禁止进入第 101/21 天改判。

同时把第一轮的受损建筑、温室、四账可胜性、0 储量恢复和防守/保护提案补成可执行条文；四账已从第 1 天覆盖到终局夜，濒死倒计时起点也已闭合。规范条文与纸面验收矩阵见 `docs/规则澄清包_V1.3.1.md`。这些条款在真实试玩前应先修“可执行性”，再调数值；不要把它们当成普通强弱平衡问题。

第三轮针对“不同主持人是否会给出同一结算、玩家是否获得足够但不泄密的信息、反馈指标能否复算”，经拆分复核共新增 10 个 P1（C-15—C-24），并强化 C-01/C-07/C-09/C-11：

1. 普通事件日程、卡表、内部权重和抽后去向缺源时，模块明确停用，禁止主持人自编；
2. 危机统一进入候选表，以等级、公开优先级和稳定 ID 决胜，并在玩家选择前公开成本、目标和全部结果带；
3. 完整评分表未入库前只能记录已定义诊断值，不能拼总分、排名或多营地胜者；
4. 玩家视图、主持审计视图和预知能力使用字段级公开矩阵，四账不得泄露隐藏保证路线；
5. 试玩记录补齐版本、模式、难度、地图/种子、事件和危机暴露上下文，只在可比较样本组内触发调参；
6. 所有已消费日常行动进入互斥穷尽标签，行动占比使用真实团队总行动分母；
7. 疾病持续时间归零后在次晨结算最后一次每日效果，再正式移除；
8. 战斗结束仍濒死者进入最近清晨救治窗口；缺源的“重伤检定”明确停用；
9. 信标区分可修复停机与不可普通维修的已摧毁状态，并补齐天线/设备名额失败转移；
10. 信标行动账按五段分别向上取整，不能按总进度合并少计行动。

## 试玩反馈门

每局至少记录规则版本、模式、难度、人数/职业、地图配置或种子、岛屿特性、救援结果、事件序列、危机 ID/等级/来源/标签、稳定饮水/食物日、信标节点、生命损失、首次枯竭、设备关闭和全部已消费行动分类。“没有真实选择”记录 0 个或更多实际时刻，不强迫凑数。胜率和调参门只在规则版本、模式、难度相同的样本组内计算；不足样本数只报原始结果。下一轮只改变一个压力源，禁止同时改材料、进度和伤害而失去因果。
