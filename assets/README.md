# Assets 目录规范

Git 不保存空目录，因此用本文件保留 `assets/`。后续素材按以下子目录组织：

```text
assets/
├── maps/        # 岛屿、区域、路线与营地图
├── cards/       # 职业、物品、建筑、生物、疾病、事件卡
├── icons/       # 状态、资源、行动、能源与耐久图标
├── ui/          # 面板、按钮、纹理和布局参考
└── audio/       # 环境、危机和反馈音效（若制作数字版）
```

文件名使用小写英文与连字符；每个外部素材必须记录作者、许可证、来源 URL 和修改情况。没有明确授权的网络图片不得进入仓库。
