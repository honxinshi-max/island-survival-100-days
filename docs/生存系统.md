# 生存系统

## 1. 目标与职责

生存系统不是单独的“掉血条”，而是限制团队可以投入建设和救援的行动预算。饱腹、水分、体温、疾病、伤势与营地事件分别结算；检定减值合计最低为 −2，但生命损失和禁止行为不互相覆盖。

本页按 `docs/规则澄清包_V1.3.1.md` 更新；与下方简表冲突时，以澄清包的完整条文为准。

## 2. 每夜权威结算顺序

1. 先决定自动防御是否支付 2 能源。普通事件模块只有在抽取日程与完整卡表入库后才建立事件槽；当前缺源时明确跳过，不得临时补事件。字段完整的阶段、周期和事件触发危机进入统一候选表，只保留一项后按“已取得的危机预防 → 危机应对/止损 → 其余营地防御战”结算。其他反应型设备在触发时决定支付。
2. 扣除饱腹和水分基础消耗。
3. 结算饥饿、脱水造成的生命和次日行动惩罚。
4. 结算体温变化、高温和低温后果。
5. 支付尚未结算的持续设备、信标广播或待机能源。
6. 食物腐败、状态持续时间减少；疾病减至 0 时先标“待到期”，不在此处移除。
7. 次日清晨结算流血、疾病、感染与传染。

灾害在第 1 步摧毁电力或信标设施，会直接影响同夜广播。

## 3. 普通检定

`差值 = 检定总结果 − 目标值`：

| 差值 | 等级 |
|---:|---|
| +3 及以上 | 超额成功 |
| 0 至 +2 | 成功 |
| −1 | 部分成功 |
| −2 及以下 | 失败 |

天然 1/6 不自动改变等级。项目进度依次为 3/2/1/0。

## 4. 饱腹与水分

- 饱腹 15—29：生命 −5、次日行动 −1；1—14：生命 −10、次日行动 −1、体力类检定 −1；0：生命 −20、次日行动 −1、体力类检定 −1，并禁止高强度行动。
- 水分 15—24：生命 −5、次日行动 −1；1—14：生命 −15、次日行动 −1、所有检定 −1；0：生命 −30、次日行动 −1、所有检定 −1，并禁止高强度行动。
- 饥饿与脱水的行动惩罚同时存在时合计仍为 −1；检定惩罚可叠加至 −2；生命损失分别应用难度倍率。
- “每天最低 1 行动”只防止减值把清醒角色压成零，不解除行为禁令，也不能返还已经消费或预支的行动。

兜底标签：高强度行动包括狩猎、伐木、采矿、搬运、建造、维修、游泳和战斗中的攻击/保护/逃跑；体力类检定指这些行动附带的检定或卡牌明确标记“体力”的检定。休息统一为非战斗、未被事件拘束时支付 1 日常行动；本身不自动恢复数值，只触发明写的休息效果。卡牌明确标签优先。

## 5. 体温

1. 野外无住所时将天气变化绝对值加倍。
2. 冷/热分别使用对应衣物和住所防护。
3. `环境变化 = W方向 × max(0, |W| − 有效防护)`。
4. 再加潮湿、篝火、料理、疾病和装备效果。

潮湿使衣物寒冷防护减半；篝火每夜消耗普通燃料 1，提供体温 +8。烹饪燃料不能同时支付取暖。

## 6. 濒死、稳定与清晨救治

- 生命到 0 后进入濒死并放置 2 枚标记；进入当轮结束不移除，从其后的每个完整战斗轮结束移除 1 枚，清空前未稳定则死亡。
- 绷带可用一次战斗行动稳定到 1 生命；医生的医疗包按职业规则恢复。
- 濒死时再次受到攻击或灾害伤害立即死亡。
- 战斗结束时仍未稳定的濒死者保留生命 0 和标记，在最近一次清晨与其他濒死者进入同一个救治窗口；等待期间不取得激活机会，也不因另一场战斗结束扣标记，再次受到攻击或灾害伤害仍立即死亡。
- V1.3.1：清晨先结算流血、疾病、轻症、感染与传染，再计算当日行动并开启一次紧急救治窗口。窗口对象为所有尚未稳定的濒死者。每名清醒、未被拘束且有至少 1 行动的救治者最多救治一人；该行动已消费且不由最低行动规则返还。窗口关闭仍未稳定者死亡。
- 完整清晨顺序为：日数与每日标记重置 → 状态结算 → 计算行动 → 紧急救治 → 未救治者死亡 → 资源恢复 → 建筑产出 → 驯兽上限与喂食 → 日间行动。

### 战斗时点兜底

- 防守在单位下一次激活机会开始时结束；眩晕或跳过行动也会产生激活机会并先清除防守，最迟不超过下一轮结束。
- 一次攻击最多转移一次保护；保护者必须同区、清醒、非濒死且是合法目标，不能保护自己，也不能在同一次攻击中再次被保护。
- 进入濒死的当轮结束不移除标记；从后续每个完整战斗轮结束各移除 1 枚。稳定清空标记，再次降至 0 时重置为 2 枚。

### 终局夜

第 100/20 夜完成夜间第 1—6 步后，只做一次终局健康闭合：结算状态伤害、行动资格、紧急救治和死亡；不产生第 101/21 天的资源、建筑、动物或行动。健康闭合后先判全员死亡，再判信标是否仍锁定；结果确定后不得用下一天效果改判。

## 7. 资源与枯竭

- 快速可再生：漂流木、贝类、鱼、纤维、野果、野菜、草药、芦苇。
- 慢速可再生：木材、树脂。
- 不可再生：废金属、石料、黏土、铁矿、导能矿、晶石、机械零件、遗迹资料。
- 无限：沙土、海水、污水。

完整版快速资源每 5 天恢复初始储量 20%，慢速每 20 天恢复 20%；20 天版分别为每天和每 4 天。每个计划恢复日执行 `min（初始储量，当前储量 + ceil（初始储量 × 20%））`。当前为 0 也照常恢复；“枯竭”只表示当前不可采集，不再额外跳过恢复。

## 8. 驯服动物边界

- 有驯兽师时上限为最高职业等级 +1；无驯兽师时可维持 1 只但不能新增。
- 每个清晨按存活职业重算上限，团队选择超额动物离开；离开无掉落且不会自动返回，然后才支付保留动物的食物。
- 动物生命到 0 后受伤、不能行动但仍占上限；必须在下一次夜间第 1 步前支付食物 1 和一名角色的治疗行动 1，否则死亡。

## 9. 疾病与治疗

疾病同样使用统一检定。部分成功产生轻症；有持续时间的疾病在夜间第 6 步减少 1 天，减至 0 时标记待到期，次晨仍结算最后一次每日效果后移除；明确写“立即结束疾病”的治疗优先。无自然持续时间的疾病只在次晨复检一次。每名患者的每种疾病每天最多接受一次能治愈或缩短病程的治疗；多名传染患者只触发一次最高目标值检定，并按额外患者最多 +2。

V1.1 的“重伤检定”缺少触发时点、目标值、结果区间和状态表，本版本停用，主持人不得自拟；稳定至 1 生命后不额外掷重伤。

## 10. 生存 UI 必须显示

- 当日行动：总量、已消费、预支、禁止动作；
- 饱腹、水分、体温当前区间及“今晚将发生什么”；
- 疾病/伤势的下一结算时点；
- 安全食物/饮水恢复点，而不只显示份数；
- 夜间 7 步结算日志，禁止把多项伤害合并成一个无来源数字。
- 清晨九步日志、每名救治者的紧急救治使用状态，以及动物上限变化原因。
