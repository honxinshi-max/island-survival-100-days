# 生存系统

## 1. 目标与职责

生存系统不是单独的“掉血条”，而是限制团队可以投入建设和救援的行动预算。饱腹、水分、体温、疾病、伤势与营地事件分别结算；检定减值合计最低为 −2，但生命损失和禁止行为不互相覆盖。

## 2. 每夜权威结算顺序

1. 决定自动防御是否支付 2 能源，结算夜间事件、灾害与营地防御战；反应型设备在触发时决定支付。
2. 扣除饱腹和水分基础消耗。
3. 结算饥饿、脱水造成的生命和次日行动惩罚。
4. 结算体温变化、高温和低温后果。
5. 支付尚未结算的持续设备、信标广播或待机能源。
6. 食物腐败、状态持续时间减少。
7. 次日清晨结算流血、疾病、感染与传染。

灾害在第 1 步摧毁电力或信标设施，会直接影响同夜广播。

## 3. 普通检定

`差值 = 检定总结果 − 目标值`：

| 差值 | 等级 |
|---:|---|
| +3 及以上 | 超额成功 |
| 0 至 +2 | 成功 |
| −1 | 部分成功 |
| −2 及以下 | 失败 |

天然 1/6 不自动改变等级。项目进度依次为 3/2/1/0。

## 4. 饱腹与水分

- 饱腹 15—29：生命 −5、次日行动 −1；1—14：生命 −10、体力类检定 −1；0：生命 −20，并禁止高强度行动。
- 水分 15—24：生命 −5、次日行动 −1；1—14：生命 −15、所有检定 −1；0：生命 −30，并禁止高强度行动。
- 饥饿与脱水的行动惩罚同时存在时合计仍为 −1；检定惩罚可叠加至 −2；生命损失分别应用难度倍率。
- “每天最低 1 行动”只防止减值把清醒角色压成零，不解除行为禁令，也不能返还已经消费或预支的行动。

## 5. 体温

1. 野外无住所时将天气变化绝对值加倍。
2. 冷/热分别使用对应衣物和住所防护。
3. `环境变化 = W方向 × max(0, |W| − 有效防护)`。
4. 再加潮湿、篝火、料理、疾病和装备效果。

潮湿使衣物寒冷防护减半；篝火每夜消耗普通燃料 1，提供体温 +8。烹饪燃料不能同时支付取暖。

## 6. 濒死、稳定与清晨救治

- 生命到 0 后进入濒死并放置 2 枚标记；每轮结束移除 1 枚，清空前未稳定则死亡。
- 绷带可用一次战斗行动稳定到 1 生命；医生的医疗包按职业规则恢复。
- 濒死时再次受到攻击或灾害伤害立即死亡。
- 被动结算导致濒死者必须在次日清晨伤病结算结束前得到救治。
- V1.3 草案：每名救治者每个清晨最多执行一次预支救治；该行动已经消费新一天第 1 点行动，最低行动规则不返还它。

## 7. 资源与枯竭

- 快速可再生：漂流木、贝类、鱼、纤维、野果、野菜、草药、芦苇。
- 慢速可再生：木材、树脂。
- 不可再生：废金属、石料、黏土、铁矿、导能矿、晶石、机械零件、遗迹资料。
- 无限：沙土、海水、污水。

完整版快速资源每 5 天恢复初始储量 20%，慢速每 20 天恢复 20%；20 天版分别为每天和每 4 天。V1.3 草案取消“归零额外跳过一次恢复”，避免所有玩家都被迫永远留 1 份。

## 8. 疾病与治疗

疾病同样使用统一检定。部分成功产生轻症；有持续时间的疾病减少 1 天，无自然持续时间的疾病只在次晨复检一次。每名患者的每种疾病每天最多接受一次能治愈或缩短病程的治疗；多名传染患者只触发一次最高目标值检定，并按额外患者最多 +2。

## 9. 生存 UI 必须显示

- 当日行动：总量、已消费、预支、禁止动作；
- 饱腹、水分、体温当前区间及“今晚将发生什么”；
- 疾病/伤势的下一结算时点；
- 安全食物/饮水恢复点，而不只显示份数；
- 夜间 7 步结算日志，禁止把多项伤害合并成一个无来源数字。
