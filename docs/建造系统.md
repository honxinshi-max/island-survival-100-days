# 建造系统

## 1. 项目行动

建造、研究、维修每次默认消耗 1 日常行动，按统一检定取得 3/2/1/0 进度。独立项目在第一次检定掷骰前支付全部材料与样本；可独立部件在该部件第一次检定前支付。第一次检定失败时项目仍已启动，失败本身不自动返还；检定结算后主动取消，仍按下方取消规则处理，禁止先免费试投再决定是否投入。

每名协助者在掷骰前支付 1 日常行动，必须同区且不能同时是执行者；每次最多两人。非专业替代的额外 1 行动只由执行者支付。失败时执行者与协助者的行动都不返还。

材料顺序：`基础需求 → 模式系数 → 人数倍率 → 非专业加耗 → 向上取整 → 职业减免`。基础需求大于 0 的材料最终最低 1。

取消完成度按“已应用进度 ÷ 项目总进度”计算；独立部件分别算，信标按五段合计算。严格低于 50% 时，每种未加工基础材料返还支付量的一半并向下取整；恰好 50% 起不自动返还，加工材料与样本默认不返还。

## 2. 研究与专业替代

- 普通研究允许任何角色执行；科学家只把自己获得的基础研究进度翻倍。
- 明确标记的专业项目缺少对应职业时，材料 +50%、每次行动额外消耗 1、难度 +1、品质最高普通。
- 求救信标允许专业替代；机械狂人或科学家可免除对应替代惩罚。
- 高级研究样本在首次启动支付，暂停不重复，取消后重启要重新支付。

## 3. 建筑耐久状态（V1.3.1 草案）

| 状态 | 条件 | 运行效果 |
|---|---|---|
| 完好 | `2 × 当前耐久 > 最大耐久` | 满效 |
| 受损 | 当前耐久 ≥ 1 且 `2 × 当前耐久 ≤ 最大耐久` | 可量化正向效果减半并向下取整，最低可为 0 |
| 停机 | 当前耐久 0 | 不运行 |

受损时能源、燃料、水、材料与设备名额不减半；仓储和居住容量不减半；科技前置、治疗等级和自动取消灾害等二元能力默认不可用，除非卡牌标记“受损可用”。耐久 0 默认可维修：既有物品留在同区且只能取出，角色不再取得住所防护。只有“摧毁”才移除建筑；内容物先转入同区公开区，没有明示额外损失时数量不变。求救信标继续使用专门门槛。

## 4. 能源与设备上限

- 发电进入当日可用能源；夜间第 5 步后只保留 `min（剩余能源，6 × 可用独立电池数）`，无独立电池时保留 0。配方内部电池不计。
- 当前设备名单：发电机、高级净水器、主动机械排水、主动自动防御、执行启动/广播/待机的求救信标。温室、被动能力、电池和个人装备默认不占名额。
- 设备首次成功运行前检查名额；无空位时不运行也不付费。同一设备同日多次运行只占 1 个名额，成功运行后不能靠关机释放。发电机占 1；信标同日启动并广播合计占 1。
- 无机械狂人上限 2；机械狂人的上限为职业等级 +1。
- 上限当日下降时，团队选择不超过新上限的已登记设备保留资格；其余关闭，既有结果不倒退。能源不足时在扣除前公开决定优先级，能源不得为负。

## 5. 关键生产设施

- 排水设施：被动减半暴雨/洪水建筑伤害；灾害时支付 1 能源可取消积水和仓库损失。
- 高级净水器：每日 1 能源 + 海水/污水，产出安全淡水 4。
- 自动防御：每夜 2 能源，提供自动攻击和被动防御。
- 温室 V1.3.1：完工后最早下一清晨运行；先选作物并支付安全淡水 1，同一清晨产野菜 2 或草药 1。受损时为野菜 1、草药 0；缺水只跳过本次，不补发。

## 6. 求救信标

信标是单一大型项目，含塔架、天线、发射、控制储能、最终校准五段。4 人完整版基础总进度 30；20 天版进度使用 25%、材料使用 40%。五段难度依次为 7/9/9/9/11。

### 进度边界（V1.3 草案）

一次检定的进度只投入检定开始时的当前里程碑，超出该段的进度不结转。每一段至少需要一次按本段难度执行的新行动；最终校准不能被前一段的低难度超额进度完成。

### 启动与胜利

- 启动耗能 1，不包含同夜广播 3 能源。
- 每夜先结算灾害和战斗，再检查耐久、天线、基础检查、屏蔽和能源。
- 状态固定为：未完工、待启动、已启动（连续 0/1/2 夜）、已锁定、停机、已摧毁。耐久 0 或明示关机进入可修复停机；摧毁进入终止状态并移除，不能普通维修回场。
- 临时断电、检查缺席、临时屏蔽、天线暂不可用、无设备名额或耐久 1—50% 会使连续数归零，但保持已启动；恢复后不重付启动 1。耐久 0 或明示关机修复后回到待启动，必须重付启动 1。
- 连续三夜后锁定；之后每夜需要信标设备名额、可用天线、无屏蔽并待机 1。可恢复条件失败时回到已启动 0 夜；耐久 0/明示关机进入停机；摧毁进入已摧毁。
- 百日版最迟第 98 天白天启动；20 天版最迟第 18 天。
- 最终还需至少一名非濒死幸存者。

## 7. 开局四账可胜性检查（V1.3.1 草案）

标准路线按全部开局角色存活，从第 1 天排到终局夜；只要路线必需的 V1.1、完整高级材料配方、信标全部前置、普通建筑 20 天材料系数、卡表或地图字段缺失，就只能标记“待确认”，不能宣称四账、完整依赖拓扑或发电—广播能源账通过。

1. 材料：每种不可再生材料分别满足 `保证可得量 ≥ 路线需求 + ceil（路线需求 × 10%）`；样本、内部电池、加工燃料、维修与运行投入均计入，已消费物品不能重复作为库存或另一配方输入。
2. 行动：按普通成功 2 进度制作全周期逐日依赖计划；信标必须逐段计算 `Σceil（各段进度 ÷ 2）`，不得按总进度合并取整。完整版 3/4/5 人基准建造行动为 15/15/20，20 天版均为 5。另纳入移动、采集、加工、研究、建造、协助、维生、发电、启动和广播保障；满足 `可用行动 ≥ 计划行动 + ceil（计划行动 × 15%）`，不能在信标启动日停止记账。
3. 生存：前三夜是安全食水硬门；第 4 夜至终局夜仍需逐夜证明全部开局人口的食水可由保证库存、确定性恢复和已建产能承担，且保质期、处理行动和燃料同时闭合。
4. 能源/可达：终局日 `T`、启动日 `d` 必须先满足 `d ≤ T − 2`；再按信标最低能源 `1 + 9 + max（0，T − d − 2）` 核算，并从第 1 天逐日验证发电输入、电池容量、设备名额、支付顺序和关键路线。

随机事件、非保证首领掉落和玩家自创物品不得进入可胜性预算。
