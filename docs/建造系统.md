# 建造系统

## 1. 项目行动

建造、研究、维修每次默认消耗 1 日常行动，按统一检定取得 3/2/1/0 进度。独立项目在首次取得进度前支付全部材料；可独立部件分别在启动时支付。取消项目按完成度和材料类别处理返还。

材料顺序：`基础需求 → 模式系数 → 人数倍率 → 非专业加耗 → 向上取整 → 职业减免`。基础需求大于 0 的材料最终最低 1。

## 2. 研究与专业替代

- 普通研究允许任何角色执行；科学家只把自己获得的基础研究进度翻倍。
- 明确标记的专业项目缺少对应职业时，材料 +50%、每次行动额外消耗 1、难度 +1、品质最高普通。
- 求救信标允许专业替代；机械狂人或科学家可免除对应替代惩罚。
- 高级研究样本在首次启动支付，暂停不重复，取消后重启要重新支付。

## 3. 建筑耐久状态（V1.3 草案）

| 状态 | 条件 | 运行效果 |
|---|---|---|
| 完好 | 当前耐久 > 最大耐久 50% | 满效 |
| 受损 | 当前耐久 1 至 50% | 产量、防御和量化效果减半并向上取整 |
| 停机 | 当前耐久 0 | 不运行 |

求救信标的广播耐久门槛继续按专门条款执行。不可量化能力需逐卡标明受损时是否可用。

## 4. 能源与设备上限

- 发电进入公共能源池；无独立电池时，夜间设备结算后剩余能源清零。
- 每块独立安装电池增加 6 储能；作为建筑材料支付的电池不再算独立电池。
- 当日启动、生产或支付运行能源的设备占用 1 个当日运行名额，不能反复开关规避。
- 无机械狂人上限 2；机械狂人上限为职业等级 +1。
- 能源不足时在扣除前公开决定优先级，能源不得为负。

## 5. 关键生产设施

- 排水设施：被动减半暴雨/洪水建筑伤害；灾害时支付 1 能源可取消积水和仓库损失。
- 高级净水器：每日 1 能源 + 海水/污水，产出安全淡水 4。
- 自动防御：每夜 2 能源，提供自动攻击和被动防御。
- 温室 V1.3 草案：每日投入安全淡水 1，再产野菜 2 或草药 1；缺水暂停，避免百日无投入无限产出。

## 6. 求救信标

信标是单一大型项目，含塔架、天线、发射、控制储能、最终校准五段。4 人完整版基础总进度 30；20 天版进度使用 25%、材料使用 40%。五段难度依次为 7/9/9/9/11。

### 进度边界（V1.3 草案）

一次检定的进度只投入检定开始时的当前里程碑，超出该段的进度不结转。每一段至少需要一次按本段难度执行的新行动；最终校准不能被前一段的低难度超额进度完成。

### 启动与胜利

- 启动耗能 1，不包含同夜广播 3 能源。
- 每夜先结算灾害和战斗，再检查耐久、天线、基础检查、屏蔽和能源。
- 任一条件失败，连续广播归零。
- 连续三夜后锁定；之后每夜待机 1 能源，失效则锁定丢失。
- 百日版最迟第 98 天白天启动；20 天版最迟第 18 天。
- 最终还需至少一名非濒死幸存者。

## 7. 开局四账可胜性检查（V1.3 草案）

1. 材料：必要不可再生材料、保证遗迹产物、合法替代与 10% 余量。
2. 行动：标准普通成功下的探索、加工、研究、建造、移动总行动，保留至少 15% 机动余量。
3. 生存：前三天保证安全饮水和基础食物入口。
4. 能源/可达：保证发电、三夜广播、必要设备能源和截止日前关键路线。

随机事件、非保证首领掉落和玩家自创物品不得进入可胜性预算。
